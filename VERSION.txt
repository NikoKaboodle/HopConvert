hop-common.js cache version

GitHub Pages serves .js with Cache-Control: max-age=14400 (4 hours).
Every page loads the shared runtime as:

  <script src="hop-common.js?v=20261112-3"></script>

When hop-common.js changes, bump the version on all 29 pages in the same
commit, otherwise visitors keep running the previous copy for up to four
hours - which matters most for the privacy verifier, the one file whose
logic decides whether the site claims your data stayed local.

Current version: 20261112-3

style.css cache version

The same four-hour browser cache applies to the stylesheet, and the ad slot
rules live there, so the stylesheet is versioned the same way:

  <link rel="stylesheet" href="style.css?v=20261115-1" />

Bump it in the same commit as any change to style.css.

Current version: 20261115-1

Shared module cache versions

Three engines that used to be copy-pasted into individual pages now live in
their own files so the workbench and the dedicated converters can never
disagree. They are versioned the same way:

  <script src="hop-xlsx.js?v=20261115-1"></script>
  <script src="hop-xml.js?v=20261115-1"></script>
  <script src="hop-yaml.js?v=20261115-1"></script>

  <script src="workbench.js?v=20261115-1"></script>

If you change one of these, bump its version on every page that loads it
in the same commit.

Current versions: 20261115-1
