The basics

One tool for the whole format mess

Every project starts with data in a format you did not choose. An API hands you JSON. A Kubernetes manifest arrives as YAML. A partner sends an RSS feed. Somebody exports a spreadsheet as CSV. The dedicated converters on this site each solve one of those problems properly — but the moment you need XML to SQL, or CSV to YAML, or JSONL to Excel, you are back to a search box.

The workbench is that missing tool. There is one drop zone and one target picker. Drop a file in, the format is detected for you, and you choose where the data should go. Thirty combinations work, all of them handled by the same engines that power the individual converter pages — so the workbench and the dedicated tools always give you the same answer.

Like everything else on HopConvert, it is free, it needs no account, and your data never leaves your machine. If you would rather have one page per job, the JSON to CSV converter and the CSV to JSON converter are still the fastest route — the workbench is for the days when the job changes shape.

How it works

Three steps, no settings to learn

Drop the file in

Drag a file onto the drop zone or paste the text. The workbench reads the extension and the content itself, so it knows whether it is looking at JSON, JSON Lines, CSV, TSV, XML or YAML.

Pick where it should go

Choose the target format. Open the settings cog if you want a different delimiter, a MySQL or PostgreSQL dialect, a different YAML indent, or a named Excel sheet.

Copy or download

The preview updates as you type. Copy the result straight to the clipboard, or download it as a file with the right name and extension.

Why bother

Built on the same engines as the converters

The workbench is not a separate implementation that happens to look similar. It calls the same flattening, escaping, type inference and serialisation code as the individual tools, so a CSV produced here opens exactly like a CSV produced by the JSON to CSV converter, and a YAML file produced here is byte-for-byte what the JSON to YAML converter would give you.

Drag and drop

Drop the file anywhere on the drop zone. No dialog, no upload progress bar, no waiting for a server.

Format detected

The workbench reads the extension and the content, then tells you what it thinks it is. You can always override it.

Real .xlsx output

The Excel target builds an actual spreadsheet, with numbers typed as numbers and the header row frozen.

Nothing uploaded

Your file is read locally by the browser. There is no server behind this page that could see it.

FAQ

Frequently asked questions

What is the HopConvert Workbench?
The HopConvert Workbench is one page that converts between the data formats developers actually use. You drop in a file, the format is detected for you, you pick the target format, and you get the result. It understands JSON, JSONL, CSV, TSV, XML and YAML on the way in, and CSV, JSON, YAML, SQL, Markdown and Excel on the way out. It is free, needs no sign-up, and runs entirely in your browser.
Which formats can it convert?
On the input side the workbench reads JSON, JSON Lines, CSV, TSV, XML and YAML. On the output side it writes CSV, JSON, YAML, SQL INSERT statements, Markdown tables and real .xlsx workbooks. That is 30 working combinations, and every one of them is handled by the same engines that power the individual converter pages, so the answers never disagree.
Does the workbench detect the file format automatically?
Yes. The workbench looks at the file extension first, then at the content itself: text starting with an angle bracket is XML, text that parses as a single JSON document is JSON, a file where every line is its own JSON object is JSON Lines, and text that parses as a YAML mapping is YAML. Anything left over is treated as CSV or TSV, with the delimiter detected from the header row. You can always override the source format by hand if the guess is wrong.
Is my data uploaded anywhere?
No. Parsing, flattening and serialisation all happen on your own machine using JavaScript. Your file is read with the browser's FileReader API and never transmitted to a server. There is no backend on HopConvert that could see your data, and no analytics script runs during a conversion.
Is the Excel output a real spreadsheet?
Yes. The Excel target generates a genuine .xlsx workbook — a zipped SpreadsheetML file — in your browser. Numbers stay numbers and booleans stay booleans, so a leading-zero postcode or a long account number does not get mangled the way it would in a plain CSV import.
What happens to nested objects and arrays?
When a tabular target such as CSV, Excel, SQL or Markdown is chosen, nested objects are flattened into one column per leaf and nested keys are joined with a double underscore, so address.city becomes address__city. Arrays of simple values are joined with a pipe, so a list of skills becomes SQL | Python. When JSON or YAML is the target, the original structure is preserved exactly as it came in.
Is the workbench free?
Yes. The HopConvert Workbench is 100% free with no sign-up, no paid tier and no feature gates. Every converter on the site is free forever, because the work happens in your browser and there is no server bill to pass on.
